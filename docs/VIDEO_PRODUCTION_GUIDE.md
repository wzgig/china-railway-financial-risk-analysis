# 3 分钟视频成片制作说明

## 推荐成片结构

视频按 8 页幻灯片组织，节奏控制在 170-180 秒：

| 页码 | 时长 | 内容 |
|---:|---:|---|
| 1 | 15 秒 | 标题、研究对象和方法主线 |
| 2 | 25 秒 | 经营特征与财务压力 |
| 3 | 25 秒 | 数据来源与研究框架 |
| 4 | 30 秒 | 风险图谱和中心性解释 |
| 5 | 25 秒 | 文本风险指标与事件矩阵 |
| 6 | 30 秒 | 财务风险预警模型 |
| 7 | 25 秒 | 弹性风险管理模型 |
| 8 | 10 秒 | 结论和管理建议 |

## 录制思路

优先采用“PPT 放映 + 真人旁白”的方式。真人声音比合成语音更自然，也更像课程汇报。录制时不要逐字念满屏文字，画面只保留标题、图表和 2-3 个关键词，旁白负责解释逻辑。

录制顺序建议如下：

1. 打开 `outputs/video/china_railway_risk_3min_deck.pptx`。
2. 按 `docs/VIDEO_STORYBOARD.md` 的旁白稿练读一遍，把语速控制在每分钟 220-250 个汉字。
3. 使用 PowerPoint 的“录制幻灯片放映”功能录入旁白和翻页节奏。
4. 导出为 MP4，分辨率选择 1080p。
5. 导出后检查三个位置：图谱页是否清楚、模型页是否听得懂、结尾是否在 3 分钟左右。

## 自动制作路线

如果使用自动旁白，制作流程是：

```text
PPT 草稿
  -> 生成中文旁白 WAV
  -> 按每页时长设置幻灯片切换
  -> PowerPoint 导出 MP4
  -> 检查时长和画面
```

自动旁白版适合作为预览稿。正式提交前，建议至少听一遍并替换掉明显不自然的发音。
