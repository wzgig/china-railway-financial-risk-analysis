# 3 分钟视频分镜脚本

目标：展示“中国中铁风险传导 -> 风险评估 -> 风险预警”的全流程和结果。

## 结构

| 时间 | 画面 | 旁白重点 | 素材 |
|---|---|---|---|
| 0:00-0:15 | 标题页：中国中铁财务风险管理分析 | 本项目从公开数据出发，识别中国中铁风险机制、传导路径和预警信号。 | 标题、公司简称、流程图 |
| 0:15-0:40 | 经营特征图 | 中国中铁具有项目周期长、资金占用高、子公司多、业务地域广等特征。 | 经营机制图 |
| 0:40-1:05 | 数据来源页 | 数据来自年报公告、裁判文书、执行信息和企业风险平台，并经过清洗分类。 | 数据来源图标、数据流图 |
| 1:05-1:35 | Gephi 风险图谱 | 图谱显示风险在子公司、项目、地区和风险类型之间传导，高中心性节点是治理重点。 | Gephi 网络图 |
| 1:35-2:00 | 风险评估矩阵 | 通过词频权重、事件次数、金额和中心性评估发生概率与影响程度。 | 热力图、二维矩阵 |
| 2:00-2:30 | 机器学习预警 | 将财务指标、文本指标、事件指标和网络指标输入模型，得到风险等级和关键驱动因素。 | 模型流程、特征重要性 |
| 2:30-2:50 | 管理建议 | 建议强化回款、债务期限、子公司风险监测和重大风险事件预警。 | 建议清单 |
| 2:50-3:00 | 结尾 | 形成从识别、评估到预警的闭环，为大型建筑企业风险管理提供参考。 | 结论页 |

## 制作原则

- 一页只讲一个核心信息。
- 视频中少放大表，多放图谱、矩阵和流程。
- 每个结论都对应报告中的数据或图表。
- 语速控制在每分钟 220-260 个汉字。
