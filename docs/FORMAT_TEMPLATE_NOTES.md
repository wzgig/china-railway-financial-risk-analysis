# 格式模板提取记录

模板文件：`长沙理工大学本科毕业设计（论文）撰写规范样张.doc`

提取日期：2026-06-29；复核日期：2026-07-01

## 提取方式

使用 LibreOffice 将旧版 `.doc` 转换为 `.docx` 和 PDF，再渲染关键页面为 PNG，用于识别版心、页眉页脚、摘要、目录、正文标题、图表题注和参考文献格式。原始模板文件不改动、不纳入公开仓库。

## 结构要点

模板样张体现的论文结构为：

1. 中文题名。
2. 中文摘要。
3. 中文关键词。
4. 英文题名。
5. 英文摘要。
6. English key words。
7. 目录。
8. 正文，采用多级标题编号，例如 `1`、`1.1`、`2.1.1`。
9. 图题位于图下方，如 `图2.3  ...`。
10. 表题位于表上方，如 `表2-1 ...`，跨页表使用“续表”。
11. 参考文献，采用顺序编码制，示例含 `[M]`、`[J]`、`[A]`、`[C]`、`[S]`、`[EB/OL]`、`[N]`。
12. 致谢。
13. 附录。

## 版式要点

- 页面采用 A4，页边距约为上 25 mm、下 20 mm、左 30 mm、右 20 mm；页眉距边界约 15 mm，页脚距边界约 17.5 mm。
- 页眉左侧为学校标识图，右侧为论文短题名，下方有横线。正文页脚居中显示“第 X 页 共 Y 页”。
- 中文题名居中，使用黑体；“摘要”居中，摘要正文使用小四号宋体、1.5 倍行距；“关键词”标签用黑体，关键词之间用分号分隔，最后一个关键词后不加标点。
- 英文题名和 `ABSTRACT` 使用 Times New Roman 加粗并居中；英文摘要正文使用 Times New Roman、小四号、1.5 倍行距；`Key  words:` 标签加粗。
- 目录标题为黑体居中，目录条目采用点引导线和右对齐页码；一级标题加粗，二级标题缩进。
- 正文一级标题居中，二级标题左对齐，正文段落小四号宋体、首行缩进 2 字符、1.5 倍行距。
- 图题置于图下方，表题置于表上方；参考文献使用顺序编码制，条目独立成段。

## 对本项目的应用

- `paper/draft.md` 保留正文内容、图表路径和参考文献占位。
- `scripts/build_template_formatted_paper.py` 根据样张生成 `paper/course_paper_formatted.docx`，并同步转换出 `paper/course_paper_formatted.pdf` 作为版式检查稿。
- 生成脚本采用两轮渲染：第一轮识别正文起始页和目录页码，第二轮写入目录页码和正文总页数。
- 当前 Word/PDF 已按样张处理页眉、页脚、摘要、目录、正文标题、图题、参考文献分段和正文页码。终稿阶段仍需根据学校提交系统要求补齐封面个人信息。
