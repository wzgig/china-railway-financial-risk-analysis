# 格式模板提取记录

模板文件：`长沙理工大学本科毕业设计（论文）撰写规范样张.doc`

提取日期：2026-06-29

## 提取方式

使用 LibreOffice 将旧版 `.doc` 转换为 UTF-8 文本，只用于识别结构与格式示例，原始模板文件不改动、不纳入公开仓库。

## 结构要点

模板样张体现的论文结构为：

1. 中文题名。
2. 中文摘要。
3. 中文关键词。
4. 英文题名。
5. 英文摘要。
6. English key words。
7. 目录。
8. 正文，采用多级标题编号，例如 `1`、`1.1`、`2.1.1`。
9. 图题位于图下方，如 `图2.3  ...`。
10. 表题位于表上方，如 `表2-1 ...`，跨页表使用“续表”。
11. 参考文献，采用顺序编码制，示例含 `[M]`、`[J]`、`[A]`、`[C]`、`[S]`、`[EB/OL]`、`[N]`。
12. 致谢。
13. 附录。

## 对本项目的应用

- 先写 Markdown 草稿，不生成 Word。
- 草稿保留中文摘要、关键词、英文摘要、目录式标题、图表占位、参考文献、附录。
- 后续生成 Word 时，应按该样张设置章节层级、图表题注、参考文献顺序编码和附录格式。
- 若学校明确要求旧版 GB/T 7714，可在最终 Word 阶段将参考文献从 GB/T 7714-2025 切换为学校模板指定版本。
