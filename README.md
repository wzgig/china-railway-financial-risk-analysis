## GitHub 同步规则

自 2026-07-02 起，本文件夹 `知世/` 内的所有实质性改动都要：

1. 在对应 `工作记录.md` 中写清楚做了什么。
2. 使用 Git 提交改动。
3. 推送到已配置的 GitHub 远程仓库。

推送前需要检查 `git status --short` 和暂存内容，避免提交账号、Cookie、密钥、私人凭据或不必要的大型临时文件。
