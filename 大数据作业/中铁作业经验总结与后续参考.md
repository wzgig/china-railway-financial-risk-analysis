# 中铁作业经验总结与后续作业参考

本文档总结“中国中铁财务风险管理分析”这份作业的完整流程、关键产物和容易踩坑的地方，后续做大数据作业时可以按这个经验框架复用。

## 一、完整流程

### 1. 先把任务要求转成可执行清单

中铁作业一开始先整理课程要求，明确最终要完成：

- 经营特征与风险生成机制分析；
- Python 获取公开风险数据；
- Gephi 风险图谱与风险传导路径；
- 种子词、Word2Vec、jieba 文本风险指标；
- 机器学习财务风险预警模型；
- 弹性风险管理模型；
- 3 分钟左右展示视频；
- 最终报告、参考文献和可复现材料。

经验：不要一上来直接写正文。应先形成任务计划、交付物清单、数据路径和验证标准。

### 2. 建立项目结构

中铁作业使用了比较清晰的目录：

```text
configs/        配置文件，如风险词典、字段规范、停用词
data/raw/       原始公开资料
data/interim/   中间数据
data/processed/ 清洗后的建模数据
docs/           方法说明、结果说明、图表、视频指南
outputs/        图表、模型、Gephi 文件、PPT 等输出
paper/          报告正文、参考文献、Word/PDF
scripts/        可复现脚本
交付/           最终提交包
```

经验：新作业也建议一开始就搭好 `data/raw`、`data/interim`、`data/processed`、`scripts`、`docs`、`outputs`、`paper`，不要把文件全部堆在根目录。

### 3. 数据来源先记录，再分析

中铁作业先建立了资料来源记录，记录官方年报、评级报告、上交所、巨潮、裁判文书、执行信息、企查查转引线索、同业财务面板和参考文献。

经验：

- 每个数据来源都要记录网址、访问日期、用途、限制；
- 有登录、验证码、付费或权限限制的平台，不绕过限制；
- 搜索结果只能作为线索，不能直接当证据；
- 核心结论尽量来自官方披露、公开 PDF、可复核数据库或本地结构化数据。

### 4. 公开报告采集与财务指标整理

中铁作业用 `collect_official_reports.py` 归档公开年报、一季报和评级报告，再用 `extract_financial_indicators.py` 整理 2021-2025 年财务指标。

关键输出：

- 官方报告清单；
- 年报 PDF；
- 财务风险指标表；
- 财务风险趋势图。

经验：财务类作业必须保留“原始报告 -> 指标表 -> 图表 -> 报告段落”的追溯链。数字不要只写在正文里，要能回到 CSV 和原始 PDF。

### 5. 文本风险指标

中铁作业按三步做文本风险：

1. 用种子词从年报中提取风险语料；
2. 用 jieba 权重计算文本风险指标；
3. 用 Word2Vec 扩展风险词典，再计算扩展文本风险指标。

关键输出：

- 风险种子词配置；
- 年报风险语料命中明细；
- 文本风险指数；
- Word2Vec 扩展词典；
- 文本热力图和高权重风险词图。

经验：文本分析不能只堆词频，要说明词典来源、分词方法、停用词处理、权重计算方式和人工复核边界。

### 6. 风险事件与 Gephi 图谱

中铁作业先把官方披露风险事项整理为事件表，再补充司法、执行、企查查扩展样本。之后将事件表转换为 Gephi 节点、边和 GEXF 文件。

关键输出：

- 官方披露风险事件样本；
- 司法/执行/企查查扩展样本；
- 合并风险事件表；
- 节点表、边表；
- Gephi GEXF 文件；
- 中心性表；
- 风险网络图。

经验：

- 事件表字段要统一，包括主体、事件类型、风险类型、年份、地区、金额、来源、证据状态；
- `core`、`candidate`、`verify` 要分清楚；
- 中心性结果只能解释风险线索和网络位置，不能夸大成法律事实；
- 图谱视频展示时讲“风险如何连接和传导”，不要只说“我生成了 GEXF 文件”。

### 7. 风险评估

中铁作业把财务指标、文本风险、事件矩阵和图谱中心性放在一起判断风险重点。

关键判断包括：

- 2025 年收入和归母净利润下行；
- 资产负债率、合同资产、应收账款、利息保障倍数构成组合压力；
- 偿债风险、组织传导风险、市场风险、营运风险、流动性风险在文本指标中靠前；
- 合规风险和流动性风险在图谱中居于较核心位置。

经验：风险评估最好采用多证据交叉，避免只凭一个指标下结论。

### 8. 机器学习预警模型

中铁作业没有只用单家公司 5 年数据硬训练模型，而是采集 11 家同业公司 2021-2025 年财务面板，构造下一年度财务压力标签，训练 Logistic Regression 和 Random Forest。

关键输出：

- 同业财务面板；
- 训练数据集；
- 预警模型文件；
- 模型评价指标；
- 特征重要性；
- 中国中铁 2026 年观察概率。

经验：

- 样本量小的时候不要夸大泛化能力；
- 标签规则要透明；
- 训练集和测试集要按时间划分，避免未来信息泄露；
- 模型结果要表述为“观察信号”或“预警概率”，不要写成确定性预测。

### 9. 弹性风险管理模型

中铁作业额外做了弹性风险管理模型，从财务缓冲、经营缓冲、治理信用缓冲、网络韧性四个维度评价风险缓冲能力。

关键输出：

- 韧性评分表；
- 四维雷达图；
- 年度趋势图；
- 管理建议映射。

经验：选做模型要服务正文结论，不能孤立摆一张图。每个评分维度都要能解释到管理动作。

### 10. 报告、图表和视频

中铁作业后期重点做了三件事：

- 把正文改成正式论文/期刊式表达，删除过程化、任务化、AI 痕迹明显的句子；
- 按学校样张生成 Word/PDF，并检查图题、页眉页脚、参考文献、A4 页面；
- 录制 3 分钟视频，讲清楚“风险传导 -> 风险评估 -> 风险预警”。

经验：

- 图内顶部不放标题，标题放图注；
- 报告正文不要写“本文进一步生成……”“按照要求……”这类过程描述；
- 视频不需要展示所有代码，要展示数据如何流动、模型如何输出结果；
- 最终交付包要中文命名、结构清楚。

## 二、后续大数据作业可复用模板

### 1. 开始前先问清楚或提取这些信息

- 截止日期；
- 提交形式：报告、代码、数据、PPT、视频、实验截图；
- 是否要求指定平台，如 Hadoop、Spark、Hive、Python、R、数据库；
- 是否必须使用真实数据；
- 是否需要可视化；
- 是否需要查重或格式模板；
- 是否需要源码和运行截图；
- 是否有个人信息、学号、班级等封面要求。

### 2. 推荐目录

```text
大数据作业/
  任务要求.md
  作业计划.md
  数据来源记录.md
  README.md
  configs/
  data/
    raw/
    interim/
    processed/
  scripts/
  notebooks/
  docs/
  outputs/
    figures/
    tables/
    models/
  paper/
  交付/
```

### 3. 推荐工作顺序

1. 阅读要求，形成任务计划；
2. 确定数据来源和合规边界；
3. 建立目录和依赖环境；
4. 采集或导入原始数据；
5. 清洗数据并生成数据字典；
6. 做探索性分析和图表；
7. 建模或算法实现；
8. 解释结果和局限；
9. 写报告；
10. 生成交付包；
11. 最后运行一次检查。

## 三、常见注意事项

### 数据

- 原始数据不要被清洗结果覆盖；
- 大文件要区分“本地保存”和“是否提交”；
- 每个字段最好有数据字典；
- 缺失值、异常值、重复值要记录处理方式。

### 代码

- 脚本要按流程编号；
- 每个脚本要有明确输入和输出；
- 尽量避免手动改中间结果；
- 运行命令写进 README；
- 依赖写进 `requirements.txt` 或环境说明。

### 报告

- 不要写成工作日志；
- 不要堆代码截图替代分析；
- 图表要有图注和解释；
- 结论要对应数据和模型结果；
- 局限性要诚实写清。

### 视频

- 控制在要求时长内；
- 只展示关键网站、关键代码、关键结果；
- 不展示账号、Cookie、私人文件；
- 不在视频里长时间等待程序运行；
- 结尾要回到“做了什么、结果是什么、说明什么”。

### 交付

- 文件夹中文命名；
- 结构清楚；
- 最终报告、视频、代码、数据、依赖、说明分开放；
- 最终提交前确认文件能打开；
- 如果平台限制文件大小，优先提交报告、视频、代码、核心数据和说明。

## 四、中铁作业给后续作业的核心经验

1. 先搭流程，再写正文。
2. 每一步都保留可复现脚本和结果文件。
3. 数据来源记录和证据边界比“看起来很丰富”更重要。
4. 图表要服务论证，不要为了多而多。
5. 模型结果要谨慎解释，尤其是小样本模型。
6. 最终报告要像作者自己写的研究报告，避免任务说明式语言。
7. 交付包要让老师不用问就能找到报告、视频、代码、数据和依赖。
