# 需求拆解

## 一、题目对象

本次作业以协鑫能科（002015）为研究对象，重点分析其“电力+算力”业务。任务材料强调公司基于气象数据、设备运行数据、电价数据、政策数据和用户负荷数据，开发工业负荷模型、分布式能源负荷预测模型、能源调度模型、收益模型和算法评估模型，为虚拟电厂运行提供服务。

## 二、需要回答的问题

1. 从产业链供应链角度分析价值创造路径及效果。
2. 提出未来价值创造的动态能力链条，解释价值共创共享如何演化。
3. 制作场景决策解说视频，说明 2024-2027 年战略规划与价值创造之间的对应关系、演变特征和战略决策支撑点。

任务提示还要求覆盖以下知识点：

- 算电协同产品需求市场结构和市场缺口；
- 影响市场结构的宏观因素，如地缘冲突、政策、市场价格；
- 各阶段公司战略规划目标和路径；
- 算电协同产业链供应链；
- 产品市场集中度变化；
- 技术替代；
- 内部流程创新。

## 三、提交要求

1. 代码脚本：包含数据模拟/加载、网络构建、指标计算、可视化完整过程。
2. 数据集：边列表文件和必要的节点属性文件。
3. 分析报告：5000-8000 字。
4. 演示视频：3 分钟内，展示交互网络图和关键发现。

## 四、作业结构解释

任务文件中“成本管理洞察”写到“针对上述五个问题”，但前文列出了三个主要问题和多个提示点。为避免遗漏，报告将按五个分析模块组织：

1. 市场结构与市场缺口；
2. 宏观因素与政策环境；
3. 产业链供应链价值创造路径；
4. 2024-2027 年战略阶段与动态能力链条；
5. 技术替代、内部流程创新与成本管理效果。

## 五、关键边界

- 若使用模拟数据，必须在数据来源与处理章节明确说明模拟逻辑。
- 网络指标用于解释结构位置和管理含义，不能写成真实交易规模。
- 报告应以“价值创造与成本管理”为主线，社会网络分析是论证工具，不是孤立展示图谱。
