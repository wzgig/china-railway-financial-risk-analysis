# 数据字典草案

## 一、节点表 `nodes.csv`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| node_id | string | 节点唯一编号 |
| node_name | string | 节点名称 |
| node_type | string | 节点类型 |
| stage | string | 主要阶段，取值为 2024、2025、2026、2027、all |
| value_role | string | 价值创造角色 |
| cost_role | string | 成本管理角色 |
| evidence_level | string | 证据等级 |
| source_id | string | 来源编号 |
| note | string | 备注 |

## 二、边表 `edges.csv`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| source | string | 起点节点编号 |
| target | string | 终点节点编号 |
| edge_type | string | 边类型 |
| weight | number | 1-5 分相对权重 |
| stage | string | 对应阶段 |
| scenario | string | 业务场景 |
| cost_mechanism | string | 成本管理机制 |
| value_outcome | string | 价值结果 |
| evidence_source | string | 来源编号 |
| evidence_level | string | 证据等级 |
| note | string | 备注 |

## 三、指标表 `network_metrics.csv`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| node_id | string | 节点编号 |
| node_name | string | 节点名称 |
| degree | number | 度数 |
| weighted_degree | number | 加权度 |
| degree_centrality | number | 度中心性 |
| betweenness_centrality | number | 中介中心性 |
| pagerank | number | PageRank |
| community | string | 社群编号 |
| interpretation | string | 管理含义 |
