# 网络建模方案

## 一、建模目标

构建协鑫能科算电协同价值创造网络，解释公司如何通过能源资产、虚拟电厂、数据模型、交易市场和客户场景形成价值共创共享机制。

## 二、节点表设计

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| node_id | 节点唯一编号 | `N001` |
| node_name | 节点名称 | 协鑫能科 |
| node_type | 节点类型 | company、platform、resource、market、customer、policy、capability |
| stage | 主要对应阶段 | 2024、2025、2026、2027、all |

| note | 说明 | 来自年报/官网/模拟 |

| 字段 | 说明 | 示例 |

## 四、权重规则

边权重采用 1-5 分。第一版可按以下规则设定：

| 分值 | 含义 |
| --- | --- |
| 5 | 公司公开披露且与核心战略高度相关，具有明确业务数据或政策支撑 |
| 4 | 公司公开披露，业务相关度高，但缺少完整量化数据 |
| 3 | 行业公开资料或政策逻辑支持，适合作为结构性连接 |
| 2 | 根据产业链逻辑补充，作为辅助连接 |
| 1 | 探索性模拟连接，只用于情景展示 |

报告中应说明：权重表示网络分析中的相对重要性，不等同于真实交易金额或真实收入占比。

## 五、网络指标

- 度中心性：识别连接最多的资源、能力或市场节点；
- 加权度：识别价值创造强度较高的节点；
- 中介中心性：识别跨资源、平台、市场和客户之间的桥梁节点；
- PageRank：识别在整体网络中影响力较强的节点；
- 社群划分：识别清洁能源供给、虚拟电厂调度、算力客户、市场交易等子网络；
- 最短路径/关键路径：解释“清洁能源-虚拟电厂-算法模型-算力客户-收益反馈”的路径。

## 六、可视化方案

1. 静态图：用于报告正文，图内不放标题，标题写在图注中。
2. 交互图：用于视频演示，可按节点类型着色、按边权重调整线宽。
3. 指标柱状图：展示中心性排名前 10 的节点。
4. 阶段演化图：展示 2024-2027 年网络由能源资产向算电协同生态扩展的过程。

## 七、管理解释框架

| 网络发现 | 管理含义 |
| --- | --- |
| 虚拟电厂平台中介中心性高 | 平台承担跨主体调度和交易协调功能，是成本优化的关键 |
| 数据模型能力节点 PageRank 高 | 算法模型把气象、电价、设备和负荷数据转化为调度决策 |
| 用户侧负荷节点连接增强 | 需求响应和可调负荷成为价值共创的重要来源 |
| 绿电交易与辅助服务节点形成社群 | 价值创造从供能收入延伸到市场化交易和调节收益 |
| AIDC/算力客户与清洁能源连接增强 | 低碳稳定供能成为算力业务竞争力的重要支撑 |
