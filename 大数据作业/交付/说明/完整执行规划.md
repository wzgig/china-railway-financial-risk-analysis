# 协鑫能科算电协同价值创造网络分析完整执行规划

## 一、作业目标

本作业围绕协鑫能科（002015）“电力+算力”经营业务，使用社会网络分析方法刻画算电协同产业链供应链中的资源连接、数据流动、调度控制、市场交易和价值分配关系。最终成果需要说明公司价值创造路径及效果，提出 2024-2027 年价值创造的动态能力链条，并用交互网络图完成 3 分钟内场景决策解说。

## 三、核心研究框架

### 1. 研究问题

1. 协鑫能科如何通过算电协同产业链供应链实现价值创造？
2. 虚拟电厂、算法模型、储能、用户侧负荷和电力市场在网络中分别承担什么角色？
3. 2024-2027 年政策与市场变化如何推动公司战略演化？
4. 未来价值创造的动态能力链条如何形成，并如何实现价值共创共享？
5. 网络结构如何解释成本管理，包括能源成本、调度成本、交易成本、协调成本和绿色合规成本？

### 2. 五个成本管理洞察模块

| 模块 | 报告问题 | 网络定量支撑 |
| --- | --- | --- |
| 市场结构与市场缺口 | 算力增长、绿电需求和电力调节能力之间的缺口 | 算力客户、清洁能源、储能、虚拟电厂平台的连接数量和加权度 |
| 宏观因素 | 政策、地缘冲突、能源价格、电力市场规则、碳约束如何影响价值网络 | 政策节点和市场节点的中介中心性、阶段边数变化 |
| 产业链供应链 | 公司如何连接资源、平台、算法、市场和客户 | 关键路径、社群结构、PageRank 排名 |
| 2024-2027 战略阶段 | 各阶段目标和路径如何演化 | 分阶段网络密度、阶段新增节点和新增边 |
| 技术替代与流程创新 | 模型算法和内部流程如何降低成本 | 能力节点的中心性、数据流动边权重、调度边权重 |

## 四、数据建设方案

### 1. 数据来源分层

| 层级 | 来源 | 用途 |
| --- | --- | --- |
| 官方政策 | 国家发改委、国家能源局、国家数据局等文件 | 解释 2024-2027 政策背景和算电协同方向 |
| 公司披露 | 协鑫能科官网、巨潮资讯、深交所公告 | 确定公司业务、战略表述、能源服务和虚拟电厂节点 |
| 行业资料 | 电力市场、虚拟电厂、绿色算力、数据中心低碳公开资料 | 补充市场结构、集中度和技术替代背景 |
| 结构化模拟 | 按公开事实和产业链逻辑生成边权重 | 构建可运行网络，说明关系强度而非真实交易金额 |

### 2. 最终 CSV 文件

| 文件 | 字段重点 | 用途 |
| --- | --- | --- |
| `data/processed/nodes.csv` | `node_id`、`node_name`、`node_type`、`stage`、`value_role`、`cost_role`、`evidence_level` | 节点属性表，必须交付 |
| `data/processed/edges.csv` | `source`、`target`、`edge_type`、`weight`、`stage`、`scenario`、`cost_mechanism`、`value_outcome` | 边列表，必须交付 |
| `data/processed/data_dictionary.csv` | 字段名、含义、类型、取值范围 | 报告“数据来源与处理”使用 |
| `data/processed/stage_summary.csv` | 阶段、节点数、边数、密度、关键节点 | 支撑 2024-2027 战略演化 |
| `outputs/tables/network_metrics.csv` | 度中心性、加权度、中介中心性、PageRank、社群 | 支撑社会网络分析过程 |
| `outputs/tables/key_paths.csv` | 起点、终点、路径、路径长度、解释 | 支撑价值创造路径解释 |

### 3. 节点设计

节点数量建议控制在 28-45 个，既能体现产业链供应链，又不会让视频展示过于混乱。

主要节点类型：

- `company`：协鑫能科；
- `platform`：虚拟电厂平台、能源交易平台、零碳园区平台；
- `resource`：清洁能源、热电联产、储能、用户侧负荷、数据中心负荷；
- `capability`：工业负荷模型、分布式能源负荷预测模型、能源调度模型、收益模型、算法评估模型；
- `market`：电力现货、辅助服务、绿电交易、碳交易、需求响应；
- `customer`：工业用户、园区客户、AIDC/智算客户、公共机构；
- `policy`：新型电力系统行动方案、数据中心绿色低碳政策、电力市场化改革；
- `partner`：设备供应商、算力生态伙伴、地方能源平台。

### 4. 边设计

边数量建议控制在 55-90 条。边权重采用 1-5 分，代表相对重要性，不代表真实金额。

主要边类型：

- `energy_supply`：能源资源向用户、园区、数据中心供给；
- `data_flow`：气象、设备、电价、政策、负荷数据进入算法模型；
- `dispatch`：虚拟电厂平台对资源、负荷和交易进行调度；
- `market_trade`：需求响应、辅助服务、绿电交易、电力现货等市场连接；
- `technology_collaboration`：模型算法、数字平台和算力生态协同；
- `policy_constraint`：政策目标和市场规则对公司战略的影响；
- `value_share`：节能收益、调节收益、绿色溢价和收益分成。

## 五、代码流水线

| 序号 | 脚本 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- | --- |
| 1 | `01_collect_public_sources.py` | 整理来源清单，检查链接，生成资料索引 | `data/raw/source_manifest.csv` | `data/interim/source_check.csv` |
| 2 | `02_build_network_dataset.py` | 按节点和边口径生成第一版网络数据 | `configs/*.csv`、来源清单 | `nodes.csv`、`edges.csv`、`data_dictionary.csv` |

- 每个脚本顶部写清输入、输出和用途；
- 不依赖手动修改中间结果；
- 输出路径固定，方便视频演示；
- 运行失败时给出清楚的错误信息；
- 最终 README 写明完整运行命令。

## 七、报告写作规划

目标字数：5000-8000 字。建议控制在 6500 字左右。

| 章节 | 建议字数 | 内容 |
| --- | --- | --- |
| 摘要 | 300 | 研究目的、数据、方法、发现、建议 |
| 一、引言 | 800 | 算电协同背景、协鑫能科业务基础、研究问题 |
| 二、数据来源与处理 | 1000 | 公开资料、模拟规则、数据字典、权重设定 |
| 三、社会网络分析过程 | 1400 | 网络构建、指标计算、可视化结果、关键路径 |
| 四、成本管理洞察 | 2200 | 五个模块逐一回答，必须嵌入网络定量结果 |
| 五、动态能力链条 | 900 | 资源获取、数据感知、智能调度、市场交易、生态协同、收益反馈 |
| 六、局限性与改进方向 | 500 | 数据边界、模拟权重、真实交易数据缺口、后续改进 |
| 七、结论 | 400 | 回答价值创造路径、效果和战略支撑点 |

报告表达原则：

- 不写成“我运行了某某脚本”的工作日志；
- 不夸大模拟网络，不把权重写成真实交易规模；
- 每个结论要连接到网络指标、公开披露或政策文件；
- 成本管理要具体到能源成本、调度成本、交易成本、协调成本和绿色合规成本；
- 语言采用课程研究报告风格，避免模板化和口号化。

总时长控制在 180 秒以内。

| 时间 | 画面 | 解说重点 |
| --- | --- | --- |

## 九、质量检查清单

### 数据

- `nodes.csv` 和 `edges.csv` 能被脚本读取；
- 边表中的 `source`、`target` 都存在于节点表；
- `weight` 在 1-5 之间；
- `evidence_level` 区分 official、company、industry、simulated；
- 数据字典覆盖全部字段。

### 代码

- 所有脚本能按 README 顺序运行；
- 图表和指标表可重复生成；
- 依赖写入 `requirements.txt`；
- 脚本没有绝对路径绑定到个人电脑。

### 报告

- 字数在 5000-8000；
- 结构与任务要求一致；
- 每个成本管理问题都有网络指标支撑；
- 图表有图注，正文有解释；
- 局限性写清楚，不回避模拟数据边界。

### 视频

- 时长不超过 3 分钟；
- 展示交互网络图；
- 展示关键发现；
- 不展示账号、Cookie、私人文件；
- 结尾回到战略与成本管理结论。

### 交付

- `交付/报告` 放报告；
- `交付/代码` 放脚本和依赖；
- `交付/数据` 放 CSV 数据集；
- `交付/视频` 放演示视频；
- `交付/说明` 放运行说明和文件清单。
