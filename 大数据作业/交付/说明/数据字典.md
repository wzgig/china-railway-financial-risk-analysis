# 数据字典

本说明对应 `data/processed/nodes.csv`、`data/processed/edges.csv` 和 `data/processed/data_dictionary.csv`。数据由公开资料约束下的结构化网络建模生成，公开资料与模拟关系均通过证据等级字段区分。

## 一、节点表字段

| 字段 | 类型 | 含义 | 取值说明 |
| --- | --- | --- | --- |
| node_id | string | 节点唯一编号 | N001-N999 |
| node_name | string | 节点中文名称 | 自由文本 |
| node_type | category | 节点类型 | company/platform/resource/capability/market/customer/policy/partner |
| stage | category | 节点首次或主要对应阶段 | all/2024/2025/2026/2027 |
| value_role | category | 价值创造角色 | 资源、调度、市场连接、客户需求、价值分配等角色 |
| cost_role | category | 成本管理角色 | energy_cost/dispatch_cost/transaction_cost/coordination_cost 等 |
| evidence_level | category | 节点证据等级 | official/company/industry/media/simulated |
| source_id | string | 节点主要来源编号 | 对应 source_manifest.csv 的 source_id |
| note | string | 节点说明 | 说明公开资料依据或模拟边界 |

## 二、边表字段

| 字段 | 类型 | 含义 | 取值说明 |
| --- | --- | --- | --- |
| source | string | 起点节点编号 | 必须存在于 nodes.node_id |
| target | string | 终点节点编号 | 必须存在于 nodes.node_id |
| edge_type | category | 关系类型 | energy_supply/data_flow/dispatch/market_trade/technology_collaboration/policy_constraint/value_share |
| weight | integer | 相对重要性权重 | 1-5，非真实交易金额 |
| stage | category | 关系对应阶段 | all/2024/2025/2026/2027 |
| scenario | category | 业务场景 | 虚拟电厂/绿电交易/AIDC/零碳园区等 |
| cost_mechanism | category | 成本管理机制 | 能源成本/调度成本/交易成本/协调成本/绿色合规成本/收益分配等 |
| value_outcome | string | 价值结果 | 稳定供能、调节收益、绿色溢价、客户粘性等 |
| evidence_source | string | 边关系证据来源编号 | 对应 source_manifest.csv 的 source_id |
| evidence_level | category | 边关系证据等级 | official/company/industry/media/simulated |
| note | string | 边关系说明 | 说明公开资料依据、行业逻辑或模拟边界 |

## 七、使用边界

- `weight` 为 1-5 分相对重要性评分，用于网络计算，不代表真实交易金额、收入占比、合同规模或市场份额。
- `simulated` 表示根据公开事实和产业链逻辑补充的结构化关系，报告中应作为情景建模结果而非公司披露事实。
- 第一版网络用于课程作业的社会网络分析与场景决策解说，若用于正式投资、审计或经营决策，需要进一步接入真实交易、负荷和市场报价数据。
