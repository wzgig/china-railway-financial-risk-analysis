# 视频录制完整指南与脚本

本文件用于录制“大数据作业：协鑫能科算电协同价值创造网络分析”的 3 分钟以内场景决策解说视频。视频的目标不是展示完整代码运行过程，而是让老师在短时间内看清楚：数据如何来、网络如何建、关键发现是什么、2024-2027 年战略演化如何支撑价值创造。

## 一、成片要求

- 时长：建议 165-175 秒，最长不超过 180 秒。
- 画面比例：16:9，建议 1920x1080。
- 声音：语速自然，重点句稍停顿；不需要背景音乐。
- 展示重点：交互网络图、节点/边数据、中心性排名图、阶段演化图、成本机制图和结论。
- 数据边界：必须说明公开资料与结构化模拟并存，边权重是相对重要性，不是真实交易金额。
- 隐私安全：录制前关闭聊天窗口、浏览器个人主页、通知弹窗、账号头像、Cookie、私人文件夹。

## 二、录制前准备

## 四、正式口播稿（约 170 秒）

下面这版可以直接照读。录制时允许根据语速删减括号中的提示，不建议额外展开太多。

大家好，本次作业研究对象是协鑫能科，主题是“电力加算力”背景下的算电协同价值创造。我的分析方法是社会网络分析：把公司、虚拟电厂平台、清洁能源、储能、用户侧负荷、算法模型、电力市场和智算客户都看作网络节点，把能源供给、数据流动、调度、交易、政策约束和收益分配看作边。

先看数据部分。本次网络由 38 个节点和 85 条边构成。节点表和边表来自两类资料：一类是公司公告、投资者关系记录和政策文件，另一类是公开事实约束下的结构化模拟。这里需要特别说明，边权重只表示网络中的相对重要性，不代表真实交易金额、合同规模或收入占比。

现在打开交互网络图。图中不同颜色代表公司、平台、资源、能力、市场、客户、政策和伙伴。可以看到，AI 赋能虚拟电厂平台位于网络中心。它的 PageRank 为 0.146475，中介中心性为 0.483108，是连接资源、算法、市场和客户的关键协调节点。这说明协鑫能科的价值创造不是简单供电，而是通过虚拟电厂把分散资源聚合成可调度能力。

再看工商业用户侧负荷。这个节点的 PageRank 排名靠前，说明需求侧柔性资源非常重要。工商业负荷进入工业负荷模型和虚拟电厂平台后，可以参与需求响应和辅助服务，把原本被动的用电成本转化为可管理、可分配的价值来源。

能源调度模型是能力类节点中的重点。它把气象数据、设备运行数据、电价数据、政策数据和用户负荷数据转化为调度策略。AIDC/智算客户则代表新的需求端：这类客户需要稳定、低碳、可追溯的电力供应，因此成为算电协同价值扩展的重要场景。

从中心性排名图看，虚拟电厂平台、工商业用户侧负荷、能源调度模型、零碳园区能源平台和 AIDC/智算客户共同构成关键节点组。它们分别对应平台调度、需求响应、算法优化、园区场景和算力客户。

再看 2024 到 2027 年阶段演化。2024 年重点是资源连接和虚拟电厂基础能力；2025 年扩展到 AIDC 和零碳园区；2026 年强化市场交易、收益优化和收益分成；2027 年进一步形成绿色溢价、安全合规和生态协同闭环。网络边数从 31 条增加到 85 条，说明价值网络逐步从基础连接走向市场化和生态化。

最后看成本机制。算电协同对应的不只是能源成本，还包括调度成本、交易成本、协调成本、绿色合规成本和收益分配。协鑫能科未来的动态能力链条，可以概括为资源获取、数据感知、智能调度、市场交易、生态协同和收益反馈。最终结论是：公司价值创造的关键，是把能源资源、可调负荷、算法模型、电力市场和算力客户连接成可调度、可交易、可共享的价值网络。

## 六、录屏操作提示

### 1. 开场画面

建议先显示 Word 报告标题页，不要从代码文件开场。老师更关心研究对象、方法和结论，不需要先看脚本。

### 2. 数据展示

展示 `nodes.csv` 和 `edges.csv` 时，不要逐行解释。只需指出字段：

- 节点表：`node_name`、`node_type`、`stage`、`evidence_level`
- 边表：`source`、`target`、`edge_type`、`weight`、`stage`、`cost_mechanism`

### 3. 交互图展示

交互网络图是视频重点，建议至少停留 50 秒。操作顺序：

1. 先展示全图。
2. 悬停 `AI赋能虚拟电厂平台`，读 PageRank 和中介中心性。
3. 悬停 `工商业用户侧负荷`，解释需求响应。
4. 悬停 `能源调度模型`，解释算法能力。
5. 悬停 `AIDC/智算客户`，解释低碳算力需求。

### 4. 图表展示

中心性图、阶段演化图和成本机制图各停留 15-25 秒即可。不要逐项读图表，只讲“这张图证明了什么”。

## 八、常见问题处理

- 交互图打不开：使用 `交付/视频/演示素材/value_network_interactive.html`，或改展示 `value_network_overview.png`。
- 节点太密看不清：浏览器缩放到 90%，先全图展示，再通过悬停关键节点解释。
- 时间超出 3 分钟：删掉数据表展示和成本机制图，只保留交互图、中心性图、阶段演化图和结论。
- 口播卡顿：使用精简口播稿，先录一遍音频练习，再正式录屏。
- 视频体积过大：导出 1080p、30fps 即可，不需要 4K。
