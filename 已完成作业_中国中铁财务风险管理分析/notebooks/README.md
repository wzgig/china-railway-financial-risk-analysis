# Notebooks 规划

建议只放探索性分析，不把最终可复现流程完全依赖 Notebook。

| Notebook | 用途 |
|---|---|
| `01_financial_indicator_exploration.ipynb` | 财务指标趋势、同业对比 |
| `02_risk_event_exploration.ipynb` | 风险事件分布、案由和金额检查 |
| `03_text_risk_dictionary.ipynb` | 风险词典、Word2Vec 扩词、词频权重 |
| `04_model_experiment.ipynb` | 模型试验、特征重要性和可视化 |
