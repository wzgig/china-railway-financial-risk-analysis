# 风险指标框架

## 一级指标

| 一级风险 | 解释 | 数据来源 | 典型指标 |
|---|---|---|---|
| 流动性风险 | 现金流不足以覆盖短期经营和债务需求 | 年报、季报 | 经营现金流、现金短债比、流动比率 |
| 偿债风险 | 债务规模、利息负担和再融资压力 | 年报、债券公告、评级报告 | 资产负债率、有息债务、利息保障倍数 |
| 营运风险 | 回款、合同资产、存货和项目结算压力 | 年报、公告 | 应收账款占比、合同资产、周转率 |
| 盈利风险 | 毛利率下滑和成本上升 | 年报、行业数据 | 毛利率、净利率、成本费用率 |
| 项目风险 | 工期、质量、安全、分包和索赔 | 裁判文书、公告 | 项目诉讼数、索赔金额、安全处罚 |
| 合规风险 | 行政处罚、诉讼、执行、环保和安全生产 | 司法平台、企查查 | 处罚次数、执行金额、失信记录 |
| 市场风险 | 行业景气、基建投资、房地产链条、海外市场 | 年报、评级报告 | 新签合同增长率、海外收入占比 |
| 组织传导风险 | 子公司和地区风险向集团传导 | 图谱节点边表 | 中心性、社群、关键路径 |

## 风险评估二维矩阵

发生概率建议综合：

- 文本词频权重。
- 风险事件次数。
- 近三年变化趋势。
- 图谱节点连接数。

影响程度建议综合：

- 事件金额。
- 是否涉及核心子公司。
- 是否影响现金流、债务或评级。
- 图谱中介中心性。
- 是否被公告或评级报告重点提示。
