# 环境安装与运行说明

## 基础环境

- Python 版本：3.12.10
- 推荐系统：Windows 10/11
- 推荐终端：PowerShell
- 主要依赖清单：`Python依赖清单.txt`

## 安装依赖

在原项目根目录或交付包外的复现目录中运行：

```powershell
python -m pip install -r .\requirements.txt
```

若只使用交付包中的中文依赖清单，可运行：

```powershell
python -m pip install -r ".\八、依赖环境\Python依赖清单.txt"
```
