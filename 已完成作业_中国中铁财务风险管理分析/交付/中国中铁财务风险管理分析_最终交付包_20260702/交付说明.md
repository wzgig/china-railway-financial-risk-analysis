## 复现主线

项目流程为：

```text
公开报告与风险线索采集
  -> 财务指标、文本语料、风险事件清洗
  -> 风险图谱构建与中心性分析
  -> 财务、文本、事件和图谱联合评估
  -> 同业面板机器学习预警
  -> 弹性风险管理评分
  -> 报告、图表和视频展示
```

## 注意事项

- 裁判文书网、执行信息公开网和企查查等平台只使用公开可复核线索，不绕过登录、验证码、付费或权限限制。
- `四、可复现代码/中文命名脚本副本` 为便于提交审阅的中文命名副本；脚本中的相对路径沿用原项目结构，完整复现时建议在原项目根目录运行。
- `五、数据与模型结果/原始公开报告PDF` 中的 PDF 均为公开披露资料，用于支撑财务指标和文本语料复核。
- `candidate` 和 `verify` 类型外部风险样本表示证据状态，正式引用时应结合来源记录进行人工复核。
