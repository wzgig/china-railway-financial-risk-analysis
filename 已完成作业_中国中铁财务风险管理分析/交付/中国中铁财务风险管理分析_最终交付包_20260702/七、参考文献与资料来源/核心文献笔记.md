# 核心文献笔记

创建日期：2026-06-29

## 文献分组

### 1. 官方披露与信用评级

- 中国中铁 2025 年年度报告摘要：提供 2025 年营业收入、净利润、经营现金流、资产负债率、债券付息兑付等事实底座。
- 中国中铁 2024 年年度报告：提供合同资产、应收账款、信用风险、流动性风险、担保与差额补足承诺等财务附注。
- 联合资信 2025 年跟踪评级报告：提供外部评级视角，支撑“央企背景与融资渠道带来缓冲，但债务和项目资金占用仍需关注”的判断。

### 2. 财务风险预警经典模型

- Beaver(1966) 用单变量财务比率解释企业失败预测，是后续风险预警变量选择的源头。
- Altman(1968) 建立 Z-score 判别模型，适合作为财务压力标签或基线风险评分的参考。
- Ohlson(1980) 引入概率模型，支撑本项目用二分类或概率化预警输出。
- Shumway(2001) 强调动态 hazard model，提示本项目应使用时间切分，避免用未来信息预测过去。

### 3. 机器学习预警

- Barboza、Kimura 与 Altman(2017) 直接比较机器学习模型与传统模型在破产预测中的表现，可支撑 Random Forest、SVM、神经网络等模型选择。
- Lessmann 等(2015) 对信用评分分类算法做大规模基准比较，提示应建立基线模型、使用 AUC/F1 等多指标评估。
- Breiman(2001) 是随机森林方法源文献，适合小样本、多变量、非线性关系的课程项目。
- Chen 与 Guestrin(2016) 是 XGBoost 源文献，适合作为进阶树模型和特征重要性解释的依据。

### 4. 文本风险指标

- Loughran 与 McDonald(2011) 说明通用词典在财务文本中可能误判，支持本项目构建面向建筑央企和财务风险的专门词典。
- Campbell 等(2014) 证明强制风险因素披露具有信息含量，支持用年报、公告、评级报告等文本作为风险信号。
- Mikolov 等(2013) 提供 Word2Vec 理论依据，支持“种子词集 + 相似词扩充”的风险词典扩展方式。

### 5. 风险图谱与风险管理

- Bastian、Heymann 与 Jacomy(2009) 是 Gephi 软件论文，支撑图谱可视化和中心性分析工具选择。
- Hoyt 与 Liebenberg(2011) 讨论企业风险管理价值，支撑报告管理建议。
- COSO(2017) 提供企业风险管理框架，支撑“战略、绩效、风险承受能力和治理”之间的闭环论证。

## 文献使用原则

1. 官方披露用于事实判断，学术文献用于方法和解释框架。
2. 不从评级报告直接推出投资结论，只用于信用风险背景和外部评价。
3. 文本分析与机器学习部分要写清楚变量构造、样本限制和验证方式。
4. 若后续补充 CNKI 文献，应优先选择 CSSCI、北大核心、中文核心或高质量硕博论文中与建筑企业财务风险直接相关的研究。
