# 报告详细大纲

## 题目

中国中铁财务风险管理分析：基于风险图谱、文本指标与机器学习预警的综合研究

## 摘要

建议写 300-500 字，包含：

- 研究目的：中国中铁在大型基建和工程承包业务中的财务风险识别与预警。
- 数据来源：年报、公告、裁判文书、执行信息、企业风险数据。
- 方法：Gephi 风险图谱、Word2Vec + jieba 文本指标、机器学习预警。
- 主要结论：列出 3 个最重要风险、传导路径和预警结果。
- 管理建议：回款、债务、子公司治理、风险监控。

关键词：财务风险；中国中铁；风险图谱；文本分析；机器学习；风险预警

## 1 引言

1. 研究背景：建筑央企、基建投资、工程承包行业风险。
2. 研究对象：中国中铁的行业地位、业务规模和风险复杂性。
3. 研究问题：风险如何生成、如何传导、如何评估、如何预警。
4. 研究贡献：把公开事件数据、文本指标和财务模型结合。

## 2 中国中铁经营特征及风险生成机制

1. 业务结构：基础设施建设、勘察设计、工程设备、房地产及其他业务。
2. 财务特征：高资产、高负债、现金流波动、应收和合同资产压力。
3. 行业特征：项目周期长、回款慢、成本波动、政策和投资周期影响。
4. 组织特征：子公司多、地域广、风险传导链条长。
5. 风险生成机制图：项目风险 -> 回款风险 -> 现金流风险 -> 偿债风险 -> 融资和声誉风险。

## 3 数据来源与处理

1. 官方披露数据：年报、公告、评级报告。
2. 司法与企业风险数据：裁判文书、执行信息、企查查或同类平台。
3. 文本语料：年报风险披露、公告风险提示、司法文书摘要。
4. 数据清洗：主体名称统一、子公司匹配、事件去重、金额标准化、风险类别标注。
5. 合规说明：不绕过登录、验证码或权限限制，保留来源记录。

## 4 风险图谱构建与传导路径识别

1. 图谱设计：节点、边、权重和风险类别。
2. Gephi 分析：布局、中心性、社群划分。
3. 关键节点识别：高中心性子公司、风险类型或地区。
4. 风险传导路径：
   - 项目履约风险 -> 诉讼仲裁 -> 回款延迟 -> 现金流压力。
   - 子公司风险 -> 担保或合并报表压力 -> 母公司财务弹性下降。
   - 地区或行业景气下行 -> 订单和结算风险 -> 盈利风险。
5. 图谱结论：列出最关键传导链和管理重点。

## 5 描述性风险指标构建与风险评估

1. 种子词集构建。
2. Word2Vec 相似词扩充。
3. jieba 分词与权重计算。
4. 风险发生概率：词频、事件频次、年度变化。
5. 风险影响程度：涉案金额、财务指标敏感性、中心性、公告重要性。
6. 风险矩阵：高概率高影响、低概率高影响、高概率低影响、低概率低影响。
7. 主要发现：排序并解释重点风险。

## 6 财务风险预警模型

1. 建模目标与标签定义。
2. 样本选择：同业上市公司面板 + 中国中铁预测。
3. 特征工程：财务指标、文本指标、事件指标、网络指标。
4. 模型选择：Logistic Regression、Random Forest。
5. 模型评估：时间切分、Accuracy、Precision、Recall、F1、ROC-AUC。
6. 解释结果：特征重要性和关键风险驱动因素。
7. 中国中铁风险预警结论。

## 7 弹性风险管理模型，选做

1. 财务缓冲能力。
2. 经营缓冲能力。
3. 治理缓冲能力。
4. 网络缓冲能力。
5. 综合评分与管理启示。

当前已完成：`scripts/build_resilience_model.py` 已生成 2021-2025 年四维缓冲能力评分、2025 年雷达图、年度趋势图和 `docs/RESILIENCE_RISK_MANAGEMENT_MODEL.md`，报告草稿已在 6.5 节写入弹性风险管理模型。

## 8 风险管理建议

1. 强化应收账款和合同资产全周期管理。
2. 优化债务期限结构和现金流预测。
3. 建立子公司风险事件早期监测机制。
4. 将诉讼、执行、处罚等事件纳入财务风险预警系统。
5. 对高中心性风险节点实施重点治理。

## 9 研究结论

1. 总结风险机制、图谱路径、风险评估和预警结论。
2. 总结财务趋势、文本指标、图谱中心性和机器学习预警结果。

## 10 局限性与数据合规说明

1. 局限：公开数据完整性、商业平台访问限制、模型样本规模、标签构造。
2. 数据合规：不绕过登录、验证码、付费或权限限制，公开仓库不提交原始课程材料和大规模中间数据。
