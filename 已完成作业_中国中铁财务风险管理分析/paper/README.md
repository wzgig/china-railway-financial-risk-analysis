# 报告文件说明

本目录保存课程报告正文、参考文献库和当前排版草稿。

| 文件 | 说明 |
|---|---|
| `draft.md` | 报告正文 Markdown 草稿，图表路径指向 `docs/assets/figures/` |
| `references_gbt7714.md` | 按 GB/T 7714 顺序编码整理的参考文献清单 |
| `references.ris` | EndNote 可导入的 RIS 文件 |
| `references.enw` | EndNote tagged import 备用文件 |
| `references.bib` | BibTeX 参考文献库 |
| `course_paper_draft.docx` | 由 `scripts/build_course_paper_docx.py` 生成的 Word 草稿 |
| `course_paper_draft.pdf` | Word 草稿转换得到的 PDF 预览稿 |
| `course_paper_formatted.docx` | 按长沙理工大学本科毕业设计（论文）撰写规范样张生成的 Word 版本 |
| `course_paper_formatted.pdf` | 上述 Word 版本转换得到的 PDF 检查稿 |

当前格式化 DOCX/PDF 已完成 A4 版心、页眉校名图、正文页脚、摘要、目录、标题层级、图题和参考文献分段检查。终稿阶段仍需结合学校提交要求补充封面个人信息并进行最终人工校对。
